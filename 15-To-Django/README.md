# Simple Definitio #:

Django is a high-level, open-source Python web framework used to develop secure, scalable, and database-driven web applications quickly.

- 3. Django कैसे Install करें?
VS Code के Terminal में यह command चलाएँ:
# pip install django #
- Django का version check करें:
# python -m django --version #
- 4. Django में पहला Project बनाएँ
Step 1: नया Project बनाएँ।

# django-admin startproject myproject #
- Step 2: Project folder में जाएँ। 
# cd myproject # 
-Step 3: Server Run करें।
# python manage.py runserver #
