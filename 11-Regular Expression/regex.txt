Easy way to remember:
. = "anything" (one character)
[] = "only these characters"
For example:


| Character | Meaning              | Example   |            |
| --------- | -------------------- | --------- | ---------- |
| `.`       | Any single character | `c.t`     |            |
| `^`       | Start of string      | `^Hello`  |            |
| `$`       | End of string        | `Python$` |            |
| `*`       | 0 or more            | `a*`      |            |
| `+`       | 1 or more            | `a+`      |            |
| `?`       | 0 or 1               | `a?`      |            |
| `{n}`     | Exactly n times      | `a{3}`    |            |
| `{n,m}`   | n to m times         | `a{2,4}`  |            |
| `[]`      | Character class      | `[abc]`   |            |
| `[^]`     | NOT                  | `[^abc]`  |            |
| `()`      | Group                | `(cat)`   |            |
| `         | `                    | OR        | `cat\|dog` |
| `\`       | Escape               | `\.`      |            |
